# 刘迪 · Personal Portfolio

个人作品集网站，基于原生 HTML、CSS、JavaScript 构建，并通过 GitHub Pages 发布。

## 在线访问
https://xiaodyline.github.io/

## 设计方向
- Light / Editorial / Minimal
- 以开发者个人品牌与工程项目展示为核心
- 首页包含个人介绍、主题插画、项目展示、经历、技术栈和联系入口
- 项目展示使用虚构 Mock 数据，后续替换为真实项目资料
- 城市与技术主题插画使用 Inline SVG 绘制，含分层景观、桥梁、知识网络和矢量颗粒纹理

## 本地预览
直接打开 `index.html`，或使用任意静态文件服务器。
