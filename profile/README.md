## 项目

- **NeoAgent** — K12 教育 AI Agent 平台。参与教学活动全链路开发、题型运行时复用、流式渲染优化与 Agent 工具链迭代。
- **心理健康 AI 助手** — 基于 React、NestJS、LangGraph 与 RAG 的多轮对话应用，包含混合检索、重排、会话编排和身份认证。
- **[NextAI Translator](https://github.com/xiaodyline/nextai-translator)** — AI 浏览器翻译扩展，支持划词翻译、润色、总结与流式输出。
- **[GCFeed](https://github.com/xiaodyline/GCFeed)** — Go + React 短视频 Feed 系统工程实践，包含缓存、异步消息与监控。
- **语义地图实验系统** — 参与遥感影像地物提取、地理信息融合与跨语言服务集成。
